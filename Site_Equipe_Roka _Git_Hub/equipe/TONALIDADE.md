# Tonalidade oficial da Equipe Róka

A referência visual aprovada pelo usuário é [tonalidade-aprovada.png](assets/artwork/tonalidade-aprovada.png). Ela contém o título e os dois subtítulos nos fundos claro e noturno.

Esta aprovação substitui as tonalidades das prévias anteriores. A arte foi copiada integralmente do arquivo aprovado, preservando seus pixels. As seis janelas SVG em index.html mostram as respectivas regiões; o símbolo de registrado continua separado.

## Diretriz para alterações futuras

- Reutilizar esta arte em ajustes de tamanho, espaçamento, navegação e conteúdo.
- Preservar a tinta com aspecto natural, a legibilidade de cada letra, os recortes e os amassados.
- Manter as cores aprovadas nos dois temas. A troca de tema altera o fundo e os elementos monocromáticos.
- Evitar filtros de saturação, brilho, contraste, matiz e opacidade sobre os letreiros.
- Não gerar novamente o título ou os subtítulos para mudar o layout. Isso pode alterar as cores e os desenhos das letras.
- Uma nova tonalidade ou redesenho depende de pedido explícito e de prévia aprovada pelo usuário.

As medidas externas das janelas SVG foram preservadas para manter o layout. O ajuste de cor não modifica os quadrados, o carrossel, os links ou o parâmetro compartilhado de espaçamento.
